# Clicker 2.0

Моя обновлённая версия браузерного кликера: нажатия на робота приносят золото, которое можно тратить на улучшения и развитие.

## Файлы

- [index.html](index.html) — интерфейс.
- [style.css](style.css) — оформление.
- [script.js](script.js) — игровая логика.
- [Clicker2.0.zip](Clicker2.0.zip) — архив версии проекта.
- [QA-portfolio/](QA-portfolio/) — материалы и инструменты тестирования, план доработок и вспомогательные скрипты.

Код ссылается на звуки клика, меню и запуска, но аудиофайлы в текущей ветке отсутствуют.

## Запуск

Из этой папки можно запустить локальный сервер командой `python -m http.server 8000` и открыть `http://localhost:8000`.
