# Работа с QA-пакетом

Пакет находится в `Clicker2.0/QA-portfolio/`, а игровые файлы — на уровень выше. Все QA-документы собраны в [qa/](qa/); Excel-книга сохранена там же.

## Запуск проверок

Из корня репозитория:

```bash
cd Clicker2.0/QA-portfolio
npm ci
npx playwright install chromium
npm test
```

Состав проверок и ограничения описаны в [README.md](README.md).

## Шаблоны GitHub

Вложенная папка `.github/` содержит шаблон отчёта об ошибке и конфигурацию CI. GitHub автоматически использует такие файлы только из `.github/` в корне репозитория. В текущей структуре это сохранённые шаблоны; автоматический запуск CI ими не подключён.
